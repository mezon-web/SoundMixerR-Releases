# SoundMixerR 🎚️

Windows 11 x64向けのコンパクトな音量ミキサーです。
横スライダーでアプリごとの音量・ミュート、全体とアプリ別の出力先・入力先を操作できます。

**公開配布版は準備中です。** 公開後は [Releases](https://github.com/mezon-web/SoundMixerR-Releases/releases) に実行ファイルのZIPを掲載します。

![SoundMixerRのデモ表示](assets/preview.png)

## 使い方

1. 配布ZIPを展開し、`SoundMixerR.exe` を起動します。.NETランタイムは同梱しています。
2. スライダーで音量を変え、左のアイコンでミュートを切り替えます。
3. 上段の機器名を押すと標準・通話用の機器をまとめて切り替えます。各アプリの `⋯` から個別の音声セッションと出力先・入力先を変更できます。
4. トレイの左クリックか `Ctrl + Alt + V` で表示を切り替えます。ホットキーは設定から変更できます。

青緑は設定音量、バー内のオレンジは音声レベルです。音量の `*` は複数セッションで値が異なる状態を示します。

外クリック、Esc、×でトレイへ収納します。ピン留め中は最前面に残り、Esc・×では収納できます。
終了はトレイメニューまたは設定から行います。起動は手動です。

設定は `%LOCALAPPDATA%\SoundMixerR\settings.json` に保存します。更新時はアプリを終了し、新しいZIPを別フォルダーへ展開してください。

## 制約と検証

アプリが機器を独自指定している場合、機器変更にアプリ内設定や再起動が必要なことがあります。詳細画面では設定先と実際に使用中の機器を別々に表示します。
マイク音量・ミュートは機器共通です。排他モード・ASIOなど、Windows共有ミキサーを通らない音声は制御できない場合があります。

アプリ別機器設定にはWindowsの非公開APIを使用します。対応しない環境では取得・変更エラーを表示します。
検証はローカルで実施し、GitHub Actionsは使用しません。入力機器・物理操作などの未確認事項は [検証結果](docs/verification-v0.1.3.md) に記載しています。
