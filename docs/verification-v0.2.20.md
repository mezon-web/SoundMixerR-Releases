# SoundMixerR v0.2.20 検証結果

2026-11-07、設定保存・画面操作・ミュートと表示を改善し、音声ワーカーの負荷を測定しました。Windows 11 x64でローカル検証しています。

## 主な変更

- 起動時にホットキーが競合しても、表示・固定・位置などを保存できます。未登録の警告を残し、設定から再登録できます。
- 詳細画面を初回読取り中に閉じても、タイマーを再開しません。選択リストを開いたままのEscは、リストだけ閉じます。
- ミュートの連続操作は、音声ワーカー上の最新状態から順に切り替えます。デモは通常設定へ保存しません。
- 外部の経路設定が変更候補に一致すると、古い警告を消します。主要ボタンの高コントラスト配色を修正しました。
- 同名アプリにフォルダー等の補足を付け、ツールチップと詳細で識別情報を確認できます。既定以外の操作対象出力には「↗」を表示します。
- 表示用の既定6役割は、変更通知・定期再取得・再接続時に更新します。書込み直前の機器確認・読み戻しは省略していません。

## 実行した検査

Releaseビルドは警告0・エラー0。隔離Windowsデスクトップで状態・UI469項目が成功しました。実ユーザーの入力デスクトップは切り替えていません。元コードでR01・R02・R03・R06を再現し、修正後の回帰検査へ対応しました。

初回取得待ちを含む8画面の開閉で、終了後のタイマー停止とGC後の弱参照残存0を確認しました。別プロセスで試験用ホットキーを占有し、競合中の保存、占有解除後の再登録を確認しました。

実WASAPIの専用無音セッションで、完了前に重ねたミュート2操作を非ミュート・全ミュート・部分ミュートから確認しました。検査用セッションの元の音量・ミュートは復元し、読み戻しています。実機の機器音量・ミュート・既定機器・アプリ経路・通常設定は変更していません。

## 音声ワーカーの実測

同じ測定EXE・同じPC・3機器で比較しました。専用無音2セッションの条件は各3試行、32セッションは各1試行。外部セッションを含む総数はそれぞれ6・36でした。ウォームアップ後、表示静止5秒・収納静止5秒・音量連続操作を測定しています。診断コレクターの費用を含みます。

| 条件 | 状態公開1回の平均 変更前 | 変更後 |
|---|---:|---:|
| 少数セッション・表示静止 | 7.01 ms | 1.62 ms |
| 少数セッション・収納静止 | 6.68 ms | 1.16 ms |
| 多数セッション・表示静止 | 12.22 ms | 6.67 ms |
| 多数セッション・収納静止 | 9.44 ms | 4.19 ms |

少数セッションの表示静止では、5秒間の既定機器照会が378〜438回から12回になりました。全条件で収納中のメーター取得は0回でした。連続操作のキュー待ちは、少数条件で95%値が約0.03ms、多数の通常操作でも約0.06msでした。音量操作の間引きは採用していません。

多数セッションを高速に操作した条件も別に測定しました。変更後の操作完了95%値33.22ms・最大42.82ms、観測した最大待ち数2でした。一方で、この条件の状態公開間隔は最大365msへ伸びており、通常条件の結果と区別した制限として残します。詳細とばらつきはレビュー対応結果に記載しています。

これは状態公開処理の測定です。操作完了時間、実音の遅延、アプリ全体のCPU・保持メモリーの改善率へ読み替えないでください。CPU時間には試行間のばらつきがあり、削減率を主張していません。過去の合成UI測定とも別条件です。キュー件数は投入時点の観測値です。
