# SoundMixerR v0.2.15 検証結果

検証日：2026-11-04（日本時間）。Windows 11 x64、.NET 10 Desktop Runtime x64でローカル検証しました。GitHub Actionsは使用していません。

## 今回の変更

- メインの×／Alt+F4から「終了しますか？」とOK／キャンセルを表示します。キャンセル・Esc・確認画面の×ではアプリに戻ります。初期フォーカスとEnterの既定動作はキャンセルです。トレイ・設定の明示的な終了は従来どおりです。
- .NETを同梱しないframework-dependent配布に変更しました。実行には別途.NET 10 Desktop Runtime x64が必要です。第三者DLLのライセンス表記も同梱しています。

## 確認結果

- Releaseビルド：警告0・エラー0。
- 隔離Windowsデスクトップで状態・UIの372項目が成功。終了確認の所有関係、キャンセル／Esc／OK、親の操作停止と復帰、重複画面抑止、音量の対象変更時の状態、設定保存・表示・レイアウトを検査しました。
- 終了確認のボタンがウィンドウ内に収まることを検査し、100／200%相当の描画を確認しました。
- 最終ZIPを新しいフォルダーへ展開したEXEで、通常起動・トレイ起動・二重起動・終了の4モードを確認しました。終了確認のキャンセル後にプロセスが残り、OKで終了することも確認しました。
- ランタイム設定がMicrosoft.NETCore.App／Microsoft.WindowsDesktop.App 10.0.0を参照すること、coreclr.dll・hostfxr.dllなどの.NETランタイム本体を含まないことを確認しました。
- 配布ZIPのSHA-256、禁止ファイル、ユーザープロファイル・作業場所・PC名の混入を確認しました。ソース・設定・ログ・検証用画像は配布ZIPに含めていません。

今回の状態・UI検査は `--ui-only` を使用しています。ユーザーの音声設定を書き換える実音声API検査は再実施していません。配布EXEの起動検査はテスト専用の保存先を使い、ユーザーの設定を変更しません。入力デスクトップは切り替えていません。

## 過去の確認と今回の限界

v0.2.14の自動検査400項目成功、入力機器不足による1項目スキップ、音声設定12対象の復元確認は過去の結果です。同版では利用者と実タスクバー・トレイ復帰・短いテスト音・マイクの設定値変更／復元も部分的に確認しています。これらをv0.2.15の再検証結果や、実機22ケース全件の合格とはしていません。

次の範囲は今回未検証です：実際の録音・会議送信、複数機器間での実音の移動、全種類の物理キー／マウス操作、実OSのDPI変更・複数モニター、実スクリーンリーダー、数時間の連続稼働、Windows Audioサービスの停止・再開、.NET未導入PCでの案内表示。Windows 10・ARM64も対象検証外です。

マイク音量・ミュートは機器共通で、同じ機器を使う他アプリにも影響します。アプリ内の送信ミュートとは異なります。アプリ別の機器変更にはWindowsの非公開APIを使うため、環境やアプリによって適用できない場合があります。設定値の読み戻し成功は、実際の音・録音・送信の成功を保証しません。
