- ランタイム同梱EXE：通常起動、トレイ起動、二重起動による既存画面の表示を確認。各プロセスは正常終了。

## 確認した動作

v0.1.3では設定画面の「ログイン時に起動」とWindowsの自動起動登録処理を削除しました。ソース内に自動起動用レジストリの参照がないことと、設定画面から該当項目がなくなったことを確認しました。

v0.1.2では、プロセスの開始時刻・実行ファイル情報を取得できない場合も、取得できたプロセス名を保持するよう修正しました。表示名だけで別アプリを統合しないこと、プロセスが取得できない場合にセッション表示名を使うこと、名前がすべて不明の場合にPIDと分かる表記にすることも検査しました。現在の実音声セッションについて、取得可能なプロセス名が一覧へ反映されることを確認しています。

v0.1.1では音声レベル表示を音量バーの中へ統合しました。設定音量は青緑、音声レベルはオレンジです。隔離デスクトップでレベルの低い／高い描画と100～200％の画像を確認し、音量のつまみが動かないこと、ミュート行にオレンジが表示されないことを確認しました。

同名でも異なるアプリを統合しない識別、複数セッションの統合、混在音量と部分ミュート、マイク専用行、機器変更の読み戻し、部分失敗時の復元、無視された変更のエラー化、既定追従、画面内配置、設定保存・破損復旧を確認しました。

実際のWindows共有音声セッションを複数作り、まとめた音量・ミュート、ミュートを保つ音量変更、外部変更との同期、表示中のメーター取得、収納中の取得停止、新しいプロセスの検出、終了したプロセスの行削除を確認しました。無音バッファーを使用し、テスト音は再生していません。

アプリ別出力設定の書き込み・読み戻し・既定追従への復帰、および全体の出力設定で3つの役割を読み戻す処理を実機APIで確認しました。変更した設定は元の値へ戻しました。全体の機器音量は同じ値を書き戻す方法で確認しています。

画面は幅360 DIP、8行を超える一覧のスクロール、矢印キーによる音量操作、ピン留め、×・Escによる収納、表示切り替え、外部へフォーカスが移った場合の収納、メニュー中の収納抑止、機器なし表示、詳細画面の入出力選択・設定先／使用中の区別、ホットキー登録と重複検出を確認しました。

## 検証範囲の制限

- この環境には有効な入力機器がありません。マイクの音量・ミュート、アプリ別入力先変更、入力のみの実アプリについては未確認です。UI状態と共通処理のみ検査しました。
- 出力の検査はWindowsの設定値とセッション制御の確認です。異なる物理スピーカーへ音が移ったことや、第三者アプリが即時に機器を切り替えることは確認していません。
- 画面画像は隔離デスクトップ上で表示したWPF画面の描画結果です。100 / 125 / 150 / 200％は描画解像度を変えた検査で、OSの実DPI変更ではありません。
- マウス・キーボードの物理操作、通知領域アイコンの実クリック、異なるDPIの複数モニターをまたぐ操作、機器の物理的な抜き差し、長時間の連続稼働は未確認です。配置計算・通知処理は実装されています。
- 音声ポリシーにはWindowsの非公開APIを使用するため、Windows更新後に別途互換性確認が必要です。

生の検査結果と画面画像は、ソース作業フォルダーの `artifacts/v0.1.3-checks/` に保持しています。配布用のソースZIPはビルド中間生成物と検査機器の情報を含めていません。
