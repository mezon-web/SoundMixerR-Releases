# SoundMixerR v0.2.18 検証結果

2026-11-04、Windows 11 x64環境でローカル検証しました。

## 今回の変更と確認

- 起動時の保存位置への移動を描画前へ変更しました。修正前はLoaded時点の位置が保存位置と一致しないことを確認しました。
- コンパクト／ゆったり、事前のウィンドウハンドル作成あり／なしで、Loaded時点と最初の可視フレームの座標が保存した物理座標と一致しました。初回の既定配置、画面外の保存位置、収納からの再表示も確認しました。
- パッケージアプリの登録アイコンをバックグラウンドで取得します。テスト機のTeamsとCopilotの実アイコンを取得し、ミキサー行への反映と描画画像を確認しました。取得失敗時は共通アイコンを表示します。
- Releaseビルドは警告0・エラー0。状態・UI396項目が成功しました。今回、音声設定を書き換える検査は実行していません。
- 隔離Windowsデスクトップで配布EXEの通常・トレイ・二重起動・終了を確認しました。終了確認を取り消すと残り、OKでプロセスが終了しました。
- 配布ZIPの構成、SHA-256、EXEとHTMLの個人パス・PC名検査を実施しました。

## 利用環境と確認範囲

.NET 10ランタイム同梱です。ZIPをすべて展開し、版番号付きフォルダー内のSoundMixerR.exeを起動してください。操作説明とライセンス表記は同じフォルダーの使い方.htmlに収録しています。

報告元PCでの見え方、実OSのDPI変更・異DPI複数モニターでの起動は未確認です。実録音・会議への送信、複数機器間の実音移動、物理操作中の機器切断、Narrator、数時間の連続稼働、Windows Audioサービス再起動についても未確認です。

マイク音量・ミュートは機器共通です。アプリ別の機器設定にはWindowsの非公開APIを使用し、環境やアプリによって利用できない場合があります。実際の再生・録音・送信は使用するアプリでも確認してください。
