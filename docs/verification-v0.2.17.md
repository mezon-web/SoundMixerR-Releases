# SoundMixerR v0.2.17 検証結果

2026-11-04、Windows 11 x64環境でローカル検証しました。

## 変更内容

- TeamsなどのWebView2音声で、WindowsのアプリIDから登録名を取得して表示します。取得できない場合はプロセス名などを表示します。行のグループはアプリ識別情報で区別します。
- .NET 10ランタイムを同梱した単一EXEで配布します。ZIPを展開した版番号付きフォルダーにはSoundMixerR.exeと使い方.htmlが入っています。

## 確認した範囲

- Releaseビルドは警告0・エラー0。状態・UIの375項目が成功しました。
- テスト機で稼働中のTeamsとCopilotのWebView2プロセスを製品の名前判定へ通し、Microsoft TeamsとMicrosoft 365 Copilotの名前・アプリIDがWindowsの登録情報に一致しました。
- 登録名の取得失敗時の表示、アプリIDごとの識別、既存のモーダル・終了確認を回帰検査しました。
- 隔離Windowsデスクトップで、展開EXEの通常起動、トレイ起動、二重起動時の再表示、終了確認の取り消しとOK後のプロセス終了を確認しました。初回起動では同梱したWPFのネイティブDLLを専用キャッシュへ展開できました。
- ZIP内のファイル構成、SHA-256、EXEとHTMLに検査機の個人パス・PC名が含まれないことを検査しました。

## 未確認の範囲

報告元の別PCと実際のTeams会議中の再生セッションでの名前表示は未確認です。今回の確認対象は名前判定・状態・UI・配布形式で、音声設定を書き換えるAudioChecksとAppOutputAudioChecksは実行していません。

実録音・会議への送信、複数機器間の実音移動、物理操作中の機器切断、実OSのDPI変更、異DPI複数モニター、Narrator、数時間の連続稼働、Windows Audioサービス再起動は未確認です。実機22ケース全件の合格記録はありません。

マイク音量・ミュートは機器共通です。アプリ別機器設定にはWindowsの非公開APIを使用しており、環境やアプリによって取得・変更できない場合があります。設定の読み戻しに加えて、使用するアプリでも再生・録音・送信を確認してください。

更新時は旧版を終了し、新しいZIPを別フォルダーへ展開してください。操作説明と第三者ソフトウェアの表記は使い方.htmlに収録しています。
