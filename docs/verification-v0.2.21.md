# SoundMixerR v0.2.21 検証結果

2026-11-08、配布を.NETランタイム非同梱へ変更しました。音量・ミュート・機器切替などのアプリ本体の処理はv0.2.20から変更していません。

## 必要環境と配布構成

- Windows 11 x64、**.NET 10 Desktop Runtime（x64）**が別途必要です。通常の.NET Runtimeだけでは起動できません。[Microsoft公式ダウンロード](https://dotnet.microsoft.com/ja-jp/download/dotnet/10.0)。
- ZIP内は版番号付きフォルダー1つで、SoundMixerR.exeとオフラインの使い方.htmlの2ファイルです。
- アプリと必要なライブラリだけを単一EXEへまとめます。ランタイム本体とWPFのネイティブDLLは含めません。起動用apphost・NAudio・依存ライブラリのライセンス表記は説明書へ収録します。
- v0.2.20までの配布ファイルは変更せず残します。

## ローカル検証

.NET SDK 10.0.402、導入済みの.NET Desktop Runtime 10.0.13 x64で検査しました。Releaseビルドは警告0・エラー0です。
状態・UIの回帰検査469項目も再実行して成功しました。

- EXE内部のバンドル6件を検査し、アプリ、NAudio、System.Numerics.Tensors、設定メタデータだけが入っていることを確認しました。
- 埋込みruntimeconfigにMicrosoft.NETCore.App 10.0.0とMicrosoft.WindowsDesktop.App 10.0.0の共有フレームワーク参照があること、includedFrameworksがないことを確認しました。
- 展開したEXEの通常起動・トレイ起動・二重起動での復元・終了確認を、隔離Windowsデスクトップで検査しました。最小化設定のON/OFFと設定・詳細のモーダルも含みます。バンドルキャッシュへのファイル展開は0件でした。
- 探索先を、hostfxrだけがあり共有フレームワークのない試験用ディレクトリへ変更した子プロセスは、FrameworkMissingFailure（0x80008096）で終了し、アプリは開始しませんでした。利用者のインストール済みランタイムや環境設定は変更していません。
- READMEとオフライン説明書の必要ランタイム表記、ZIPの2件のパス、SHA-256、EXEとHTMLの個人パス・PC名を検査しました。

ランタイム不足の検査は探索先の隔離による模擬条件です。.NET未導入の別PCや、実際に表示される不足ダイアログの物理操作を確認したものではありません。設定・音声状態は書き換えていません。

## 検証範囲の区別

隔離デスクトップのウィンドウ状態・描画・イベント検査は、Explorerの実タスクバー操作や物理マウス・キーボードの確認とは区別しています。実OSの高コントラスト・DPI切替、実機マイク・録音・会議送信・実音移動、機器の物理切断、数時間の稼働は今回も未実施です。v0.2.20の性能値を今回の再計測として転記していません。
